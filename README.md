# 성범죄 적용법조 길잡이

지구대·파출소 경찰관이 성범죄 신고 현장에서 **피해자·가해자 나이, 행위, 방법, 상황**을 고르면
적용 가능한 **법조·죄명·법정형**과 **현장 조치 체크리스트**를 보여주는 웹 도구입니다.

- 사용: https://bandit1397.github.io/Sexual-Offense-Law-Reference/
- 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있고, 한 번 열어 두면 오프라인에서도 동작합니다.
- **참고용 도구**입니다. 최종 법률 판단은 수사부서와 검사가 합니다.
- 입력값은 기기 안에서만 계산하고, 저장하거나 전송하지 않습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `assets/laws.js` | 조문·죄명·법정형·미수/예비 근거 데이터 (법 개정 시 여기를 수정) |
| `assets/engine.js` | 판정 규칙 (연령 계산, 요건 확인, 우선순위, 위헌·시행일 처리) |
| `assets/checklist.js` | 현장 조치 체크리스트 (상황별로 필요한 항목만 표시) |
| `assets/app.js` | 화면 |
| `tests/engine.test.js` | 현장 시나리오 테스트 (`node tests/engine.test.js`) |

## 판정 원칙

1. 요건을 충족하는 조문을 모두 찾습니다.
2. 법정형이 가장 무거운 특별규정을 **주 적용 후보**로, 나머지를 **함께 검토**로 표시합니다. 가중규정(1/2 가중)은 순위에 반영하지 않으며, 법정형이 같으면 13세 미만 특별규정을 우선합니다.
3. 헷갈리기 쉬운 조문이 왜 적용되지 않는지 **적용 안 됨**에 이유와 함께 표시합니다.
4. 범행일을 기준으로 만 나이를 계산하고, 시행 전 조문은 제외합니다.

## 법령 기준 (2026-10-06 원문 대조)

형법(2026.10.2. 시행), 성폭력처벌법(2026.10.2.), 아청법(2026.10.2.), 아동복지법, 성매매처벌법, 경범죄 처벌법, 장애인복지법, 노인복지법, 스토킹처벌법, 군형법(2022.7.1.)

### 처음 받은 표와 달라진 주요 내용

- **아청법 아동·청소년은 2024.6.27.부터 만 19세 미만**입니다. "19세가 되는 해 1월 1일을 맞은 사람 제외" 단서는 삭제되었고, 그 전 범행에만 적용합니다.
- **군형법 제92조 계열은 피해자도 군인 등**(군형법 제1조제1항~제3항)이어야 합니다. 군인 가해자의 성범죄는 평시 일반 법원 관할입니다 (군사법원법 제2조제2항, 2022.7.1.).
- **아청법 제18조 일부 위헌** (2023헌가15, 2026.5.21.): 성폭력처벌법 제7조제3항(13세 미만 강제추행)에는 신고의무자 가중을 적용하지 않습니다.
- **성폭력처벌법 제3조제1항 일부 위헌** (2021헌가9, 2023.2.23.): 주거침입 + 강제추행·준강제추행 부분.
- 성폭력처벌법 제4조(특수)·제5조(친족)는 **유사강간을 규정하지 않습니다**.
- **강제추행은 예비·음모를 처벌하지 않습니다**. 형법 제305조는 판례상 미수를 처벌합니다.
- 업무상위력 추행(제10조), 공중밀집장소추행(제11조), 아청법 제8조·제8조의2, 형법 제302조·제303조는 **미수 처벌 규정이 없습니다**.
- 촬영·딥페이크(2024.10.16. 소지·시청 처벌 신설)·통신매체·성매수·성착취물·그루밍·공연음란·과다노출·성적목적 장소침입·약취유인·아동/장애인/노인 성적 학대를 추가했습니다.
- 각 결과에 공소시효 특례(성폭력처벌법 제21조, 아청법 제20조)를 안내합니다. 성착취물 제작·아동·청소년 대상 친족 성폭력은 공소시효가 없습니다.
- 성인 사이 대가 신체 접촉은 성매매가 아닙니다(성교·유사성교만 해당). 과다노출 등 경미사건은 주거가 분명하면 현행범 체포할 수 없습니다(형사소송법 제214조).

### 확인이 필요한 부분

- 화면에 `죄명 확인` 배지가 붙은 죄명은 대검 「공소장 및 불기소장에 기재할 죄명에 관한 예규」 최신본으로 다시 확인해야 합니다 (2024년 이후 신설 조문, 군형법, 경범죄 등).
- 해바라기센터 등 지역 기관 번호는 관할에 맞게 `assets/checklist.js`에 추가하세요.

## 법 개정 시 갱신 방법

1. 국가법령정보센터에서 바뀐 조문을 확인합니다.
2. `assets/laws.js`의 해당 항목(법정형 `pen`, 순위용 `p`, 시행일 `since`)과 `META`를 수정합니다.
3. 요건이 바뀌었으면 `assets/engine.js`를 수정합니다.
4. `tests/engine.test.js`에 시나리오를 추가하고 `node tests/engine.test.js`로 확인합니다.
5. `sw.js`의 `VERSION`을 올리고 커밋하면 GitHub Pages에 반영됩니다.
